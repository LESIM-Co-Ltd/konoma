### git en branches
[Git branches (b)]
   g / G            top / bottom
   l / Enter        checkout
   c                new branch
   d                delete (y=-d / !=-D)
   /                filter by name
   r                refresh listing & git status
   Tab / ⇧Tab       cycle changes/log/graph/branches/worktrees
   h / Esc  ·  q    back to changes
[Movement]
   j / k            move
[Copy branch]
   y n              branch name
[Tabs]
   t                new tab right of this one
   1 - 9            jump to tab by number
   T                tab list (switch / close)
[Global]
   P                paste a path / GitHub link and jump there (reveal + preview)
   ?                toggle this help
   F                follow mode: auto-preview externally changed files
   Q                quit (back to tree in preview)
### git en changes
[Git changes (p)]
   g / G            top / bottom
   s / S            stage / stage all
   u / U            unstage / unstage all
   x                discard file (confirm)
   c                commit (staged)
   l / Enter        file diff
   d                diff of all changes (worktree)
   b                branches
   w                worktrees
   Ctrl-t           open the entry under the cursor in a new tab
   /                filter the rows by the text they show
   r                refresh listing & git status
   Tab / ⇧Tab       cycle changes/log/graph/branches/worktrees
   !                external git tool (lazygit)
   h / Esc  ·  q    close git view
[Movement]
   j / k            move
[Launch]
   e                edit in external editor ($EDITOR / config)
   o                open in another app (OS default / Office)
[Tabs]
   t                new tab right of this one
   1 - 9            jump to tab by number
   T                tab list (switch / close)
[Global]
   P                paste a path / GitHub link and jump there (reveal + preview)
   ?                toggle this help
   F                follow mode: auto-preview externally changed files
   Q                quit (back to tree in preview)
