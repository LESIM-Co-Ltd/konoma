以下はすべて既定値で、config の `[keys.<文脈>]` で文脈ごとに変更できます(→
[設定リファレンス](../configuration/))。アプリ内では `?` がその画面のキーを、今の割当どおりに表示します。

## キーの並べ方

既定のキーは層に分けて並べてあり、**同じキーはどこでも同じ意味**になります:

| 層 | 中身 |
|---|---|
| 0. アプリ全体 | `?` `Q` `F` `P` `t` `T` `[` `]` `1`-`9` — どの画面でも同じ |
| 1. 基本 | 移動・`/` `n` `N` `r` `y` `Y` `v` `V` `m` `'` `Ctrl-t` `,` `Space` `Esc` `Enter` `q` — カーソルのある表示ならどこでも同じ |
| 2. 表示の種類ごと | 画像のズーム・ページ送りの `J` `K`・アウトラインの `O`・表現の巡回の `R`・diff のレイアウトの `s` |
| 3. 動詞 | `e` 編集 · `o` 他のアプリで開く · `p` プロジェクトの画面 · `!` プロジェクトのツール |

ツリーだけのキー(`d` `C` `a` `A` `.` `i`)と、バージョン管理の各画面の一覧用のキーもあります。ツリー以外では、
**`Space` が今見ている画面で動く操作すべてのメニューを開きます** — 各操作は既に持つキーか専用の 1 文字で並ぶので、
専用のキーが無い操作も 1 打鍵で届きます。

## 層 0 — アプリ全体(全画面共通)

| キー | 動作 |
|---|---|
| `?` | 現在の画面のヘルプ |
| `Q` | 終了(`ui.confirm_quit = false` でなければ確認。`qq` で素早く) |
| `t` | タブ新規・現在のタブの右隣に挿入(vim の `:tabnew` 相当。閉じるはツリーの `q`。`w` は vim の単語移動と誤爆するため既定未割当) |
| `[` / `]` / `1`-`9` | 前 / 次 / 番号のタブ |
| `F` | フォローモード(ディスク上の変更を自動表示) |
| `T` | タブ一覧(切替 / 閉じる。タブバーは幅超過時に `‹n / n›` で隠れタブ数を表示) |
| `P` | クリップボードのパス/GitHub リンクへジャンプ(reveal + プレビュー。`#L12` / `:12` の行アンカー対応) |

## 層 1 — 基本

| キー | 動作 |
|---|---|
| `j` `k` `h` `l`・矢印 | 移動(ツリーと一覧 — Git 画面・アウトライン / ページ一覧・タブ一覧 — では `l` が開く/潜る、`h` が戻る。ブックマーク一覧だけは `h` と `l` もブックマーク名のまま)|
| `g` `G`・`Ctrl-d` `Ctrl-u`・`Ctrl-f` `Ctrl-b`・`0` `$` | 先頭 / 末尾・半ページ・ページ・行頭 / 行末(`ui.keys = "less"` では `d` `u`・`f` `b`) |
| `q` | 戻る / 閉じる(ツリー: タブを閉じる。最後の 1 枚なら終了) |
| `Esc` | 取り消し(入力・選択・検索。何も無ければ戻る) |
| `Enter` | その画面の既定の操作(開く・展開・ジャンプ・フォーカス中のチェックボックスのトグル) |
| `/` | 検索(ツリーと一覧は入力しながら絞り込み。`Esc` で解除)— 変更一覧・ログ・グラフ・アウトライン / ページ一覧・タブ一覧・ブックマーク一覧でも効く |
| `n` / `N` | 次 / 前の一致。**検索していないときは次 / 前の変更箇所**(ツリー: 変更ファイル · コード/テキストのプレビュー: 変更ガターのブロック · 描画した文書: 変更したブロック · diff: 変更ブロック) |
| `Ctrl-n` / `Ctrl-p` | ツリー順で次 / 前のファイルをプレビュー(diff では次 / 前の変更ファイル) |
| `r` | 読み直し(ツリー・プレビュー・diff・Git 画面のすべての一覧) |
| `v` / `V` | 文字単位 / 行単位の選択(ツリー: 範囲選択 / 1 件トグル) |
| `y` | その画面のコピーメニュー(下記)· `Y` は `@path#L12-34` 参照のコピー |
| `m` + 英字 / `'` | ブックマーク登録(プレビューでは表示中ファイル)/ 一覧 |
| `Ctrl-t` | カーソルやフォーカスの指すものを別タブで開く(ツリーのエントリ · ローカルリンク · 変更一覧の行 · ワークツリー) |
| `,` | 並べ替えと表示のオプションメニュー(下記) |
| `Space` | 操作メニュー(下記) |

## 層 3 — 動詞

| キー | 動作 |
|---|---|
| `e` | 外部エディタで、見ている行を開く(Office ファイルは Office アプリで — `[external] office_apps`)。ツリー・すべてのプレビュー・diff・変更一覧の行で効く |
| `o` | 他のアプリで開く: Office ファイルは Microsoft Office / LibreOffice / OS の既定、それ以外は OS の既定(`open` / `xdg-open`)。バックグラウンドで動く。`[external] office_apps` / `open_links` で止められる。ディレクトリは開かない |
| `p` | プロジェクトの画面: Git(または jj)の変更一覧。ツリー・プレビュー・diff から |
| `!` | プロジェクトのツール: lazygit / lazyjj(`[git] tool` / `[jj] tool`)。ツリー・プレビュー・diff・変更一覧から |

## ツリー

| キー | 動作 |
|---|---|
| `j` `k` / `g` `G` | 移動 / 先頭 / 末尾 |
| `l` | ディレクトリへ潜る(ファイルはプレビュー) |
| `h` | 親ディレクトリへ |
| `Enter` | その場で展開/折りたたみ(ファイルはプレビュー) |
| `/` | 入力しながら絞り込み(`Esc` で解除) |
| `.` / `i` / `r` | 隠しファイル切替 / ファイル情報 / 更新 |
| `,` | 並べ替えと表示のメニュー: `n` 名前 · `s` サイズ · `m` 更新日時 · `e` 拡張子 · `r` 昇降反転 · `.` フォルダ先頭 · `p` パス表示(相対 / `~` / フル)· `h` 隠しファイル |
| `v` / `V` | ビジュアル範囲選択 / 1件選択トグル(`a` で兄弟、`A` で全部を選択。`q` か `Esc` で取り消し) |
| `Space` → `n r d c x p D` | 作成 / リネーム / 削除 / コピー / カット / ペースト / その場に複製 |
| `y` → `n r f p @` | 名前 / 相対 / フル / 親 / `@参照` をコピー |
| `Ctrl-t` | カーソル下のエントリを別タブで開く(ファイル=プレビュー・ディレクトリ=そのタブの root) |
| `m` + 英字 / `'` | ブックマーク登録 / 一覧 |
| `a` / `A` | 表示基準を現在地に / 起動位置に戻す |
| `d` | カーソルファイルの diff(git) |
| `C` / `n` `N` | 変更ファイルビュー / 変更ファイル間ジャンプ |
| `e` / `o` / `p` / `!` | 編集 / 他のアプリで開く / Git ハブ / 外部 git ツール |
| `q` | タブを閉じる(最後の1枚なら終了) |

## テキスト / Markdown / 文書プレビュー

| キー | 動作 |
|---|---|
| `j` `k`・`Ctrl-d` `Ctrl-u`・`g` `G` | スクロール / 半ページ / 先頭末尾 |
| `h` `l`・`0` `$` | 横スクロールと行頭/行末(折返しオフ時) |
| `/` `n` `N` | 検索 / 次 / 前の一致(検索していなければ次 / 前の変更箇所) |
| `Tab` / `Shift-Tab` | リンク・チェックボックス・`<details>`・図のフォーカス移動(文書) |
| `Enter` | フォーカス中のリンクを開く / チェックボックスや `<details>` をトグル / フォーカス中の図を全画面で開く |
| `Ctrl-t` | フォーカス中の**ローカル**リンクを別タブで開く(アンカーはその場で移動・URL はどちらもブラウザで開く) |
| `J` `K` | プレゼン: 次 / 前のスライド。絵の表示でも文字表示でも効く(それ以外と 1 枚だけのデッキでは何もしない。アクション `page_next` / `page_prev`) |
| `R` | 表現の巡回: 装飾表示 ⇄ raw ソース(Markdown/Mermaid と Word/OpenDocument 文書 — raw は変換後の Markdown)。プレゼンでは スライドの絵 ⇄ 文字表示(今のスライドは保つ)。このプレビューが diff の `preview` 表現である間は、代わりに diff へ戻る |
| `O` | Markdown プレビューの見出しアウトライン(`Enter` で見出しへジャンプ)。2 ページ以上の PDF・ブック・プレゼンではページの一覧(`Enter` でそのページへ) |
| `+` `-` `=` | フォーカス中の図をその場でズームイン / ズームアウト / フィット |
| `v` / `V` | 文字単位 / 行単位の選択 → `y` でコピー(`q` か `Esc` で選択を抜ける) |
| `y` → `n r f p @ c` | 名前 / 相対 / フル / 親 / `@参照` / フォーカス中の Markdown コードブロック(`Tab` でフォーカス)をコピー |
| `Y` | `@path#L12-34` 参照をコピー |
| `,` | `p` パス表示 · `w` 折り返し |
| `Ctrl-n` / `Ctrl-p` | 次 / 前のファイルをプレビュー(ツリー表示順・端で wrap) |
| `m` + 英字 / `'` | 表示中ファイルをブックマーク / 一覧 |
| `e` / `o` / `p` / `!` / `r` / `q` | 編集 / 他のアプリで開く / Git ハブ / git ツール / 読み直し / ツリーへ戻る |

## 画像 / PDF / SVG / 動画プレビュー

| キー | 動作 |
|---|---|
| `+` `-` / `=` | ズーム / フィットに戻す |
| `h j k l` | パン |
| `J` `K`(`PageDown` `PageUp` も) | PDF ページ送り / 戻し(アクション `page_next` / `page_prev`。旧名 `pdf_next_page` / `pdf_prev_page` も可) |

| `,` | `p` パス表示 |
| `Ctrl-n` / `Ctrl-p` | 次 / 前のファイルをプレビュー(ツリー表示順・端で wrap) |
| `m` `'` / `e` `o` `p` `!` / `r` `q` | ブックマーク / 動詞 / 読み直し・戻る |

|---|---|

| `Ctrl-n` / `Ctrl-p` | 次 / 前のファイルをプレビュー(ツリー表示順・端で wrap) |

## diff(1 ファイルの git / jj の差分)

| キー | 動作 |
|---|---|
| `j` `k` `h` `l`・`g` `G`・`0` `$`・`Ctrl-d` `Ctrl-u` `Ctrl-f` `Ctrl-b` | スクロール |
| `n` / `N` | ファイル内の次 / 前の**変更ブロック** |
| `Ctrl-n` / `Ctrl-p` | 次 / 前の**変更ファイル** |
| `s` | レイアウト巡回(unified⇄split⇄auto — 変更された画像/PDF/SVG(`[ui] diff_view = "rendered"` では並べて表示)では代わりに auto⇄side⇄stack、`[git] media_diff`) |
| `R` | そのファイルが実際に持つ表現だけを巡回(Markdown・SVG はソース⇄整形⇄プレビュー、画像/PDF は整形⇄プレビューのみ — 整形が並べて表示そのもの・`[ui] diff_view`) |
| `J` `K`(`PageDown` `PageUp` も。スクロールの代わり) | 画像/PDF/SVG の diff: 複数ページの PDF なら両側同時にページ送り(それ以外では何もしない。アクション `page_next` / `page_prev`。旧名 `media_diff_page_next` / `_prev` も可) |
| `,` | `f` フォローのスコープ(開始以降 ⇄ フル git diff)· `p` パス表示 |
| `x` | このファイルの変更を破棄(先に確認) |
| `e` | 画面にある変更ブロックの行でエディタを開く |
| `o` / `p` / `!` / `r` / `q` | 他のアプリで開く / Git ハブ / git ツール / 読み直し / 戻る |
| `y` | コピーメニュー |

## Git 画面(と jj)

`p` でツリー・プレビュー・diff から変更一覧を開きます。**`Tab` / `Shift-Tab` で画面を巡回します** — 変更・ログ・
グラフ・ブランチ・ワークツリー(jj にはワークツリーの画面が無いので巡回から飛ばされます)。どの一覧も
`j` `k` `g` `G`・`l` / `Enter`(開く)・`h` / `q`(戻る)・`/`(絞り込み)・`r`(読み直し)・`y`(コピーメニュー)・`Space`(操作メニュー)・
`Ctrl-t`(該当する所では別タブで開く)が共通です。

| 画面 | キー |
|---|---|
| 変更(`p`) | `s` `u` ファイルを stage / unstage · `S` `U` 全ファイル · `c` コミット · `x` 変更破棄(確認あり)· `d` 全変更の diff · `l` / `Enter` diff を開く · `b` ブランチ · `w` ワークツリー · `e` 行のファイルを編集 · `o` 他のアプリで開く · `!` git ツール · `Ctrl-t` ファイルを別タブで開く |
| ログ / グラフ | `l` / `Enter` コミット詳細(全文+diff)· `y` コミット情報コピー(`s h t m a d`) |
| グラフ | `s` 基準ブランチ固定 · `x` 解除 · `a` 全リビジョンを表示(jj)· `b` ブランチパネル(`x` 切替 · `a` 全部 · `c` 現在のみ · `J` `K` 並べ替え · `l` / `Enter` 適用) |
| コミット詳細 | `s` レイアウト・スクロールのキー |
| ブランチ | `l` / `Enter` チェックアウト · `c` 作成 · `d` 削除 · `/` 絞り込み · `y` → `n` ブランチ名をコピー |
| ワークツリー(`w`) | `l` / `Enter` このタブを切り替え · `Ctrl-t` 別タブで開く · `d` base ブランチからの差分 · `c` 新規作成(ブランチ名を聞き、作成後そこへ切り替え)· `/` 絞り込み |
| **jj** — 変更 | `s` jj に作業コピーを取り込ませる(唯一の書き込み・確認あり) |
| **jj** — ブランチ | bookmark 一覧(jj のポインタ。「現在」印は付かない) |
| **jj** — 変更 | `u` `S` `U` `c` `x` `w` は出ない(jj に index が無く、konoma は読むだけ) |

## メニュー: `y`・`,`・`Space`

| キー | 開くもの |
|---|---|
| `y` | その画面のコピーメニュー: ツリーとプレビューはパス(`n r f p @`、フォーカス中のコードブロックは `c`)· 表は `c` セル · `r` 行 · `C` 列 · `f` パス · コミットは `s h t m a d` · ブランチは `n` 名前 |
| `,` | その画面の並べ替えと表示のオプション(上のツリー・テキスト・diff の表) |
| `Space` | ツリー: ファイルメニュー(`n r d c x p D`)。それ以外: 今その画面で動く操作すべて(自動で作られる)— キーを付け替えた操作や単キーの無い操作もここにある。項目はその画面のフッターの順(よく使う操作が先)で、フッターの短いラベルで並ぶ |

`[keys.<文脈>]` の和音(`"y x"`・`", x"`・`"space x"`)はその文脈のメニューだけを変えます →
[設定リファレンス](../configuration/#メニューと和音)。

## タブ一覧(`T`)

| キー | 動作 |
|---|---|
| `1`-`9` / `Enter` / `l` | そのタブ / 選択タブへ切替 |
| `j` `k` | 移動 |
| `/` | 行の表示文字列で絞り込み(`Enter` で確定、`Esc` で解除。その後の `Esc` で閉じる) |
| `d` | **選択タブ**を閉じる(一覧は開いたまま・最後の1枚は拒否) |
| `T` `q` `h` `Esc` | 一覧を閉じる |

## ブックマーク一覧(`'`)

| キー | 動作 |
|---|---|
| 任意の英字 | そのブックマークへジャンプ(a-z ローカル / A-Z グローバル) |
| `j` `k` + `Enter` | 選択してジャンプ |
| `/` | 行の表示文字列で絞り込み。入力中の英字は文字であってブックマーク名ではない(`Enter` で確定、`Esc` で解除。その後の `Esc` で閉じる)|
| `Ctrl-e` | 対象をエディタで開く |
| `Space` `d` | ブックマーク削除 |
| `'` `q` `Esc` | 閉じる |

一覧やグローバルのキーに使われている英字(`F` `P` `Q` `T` `j` `k` `q` `t`)は
直接ジャンプできません — `j`/`k` + `Enter` で選ぶか、キーを再割当してください。
他の一覧と違い、ここでは `h` と `l` は「戻る / 開く」ではなく、ほかの英字と同じくブックマーク名です。

## アウトライン(`O`)・ファイル情報(`i`)・ヘルプ(`?`)

| 画面 | キー |
|---|---|
| アウトライン(PDF・ブック・プレゼンではページの一覧) | `j` `k` `g` `G` 移動 · `Enter` / `l` 見出しへジャンプ(ページへ移動) · `/` 行の絞り込み(`Enter` で確定・`Esc` で解除)· `O` `q` `h` `Esc` 閉じる |
| ファイル情報 | `i` `q` `Esc` 閉じる |
| ヘルプ | `j` `k` `g` `G` スクロール · `?` `q` `Esc` 閉じる |
