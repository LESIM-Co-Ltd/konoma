---
title: プロジェクトのキー
description: プロジェクトプラグインの画面を操作するキー。
---

ツリーとプレビューの `p` で検出したプロジェクトを開きます。複数ある場合は
`j`/`k` と `Enter` で選択し、`Esc` でキャンセルします。該当するプラグインがない場合は
従来の git/jj の画面を開きます。

| キー | 操作 |
| --- | --- |
| `Tab` / `Shift-Tab` | 画面を巡回 |
| 画面が宣言した単キー | その画面へ移動 |
| `j` / `k`、矢印 | 移動・スクロール |
| `V` | 行のマークを切り替え |
| `/` | 一覧を絞り込み |
| `Enter` | 行の種類に対応する既定の操作 |
| `Space` / `?` | 文脈に合う操作・実行可能なキー |
| `q` / `Esc` | 画面を一つ戻るか元の表示に戻る |

確認のキーと選択肢はプラグインの宣言に従います。文字入力には初期値が入ります。
どの入力画面でも `Esc` でキャンセルすると操作は実行されません。

表示の取得中に入力したプロジェクト操作は返信を待って処理します。画面を移動すると
保留中の行操作を中止します。プロジェクト画面では画面移動のキーを優先し、衝突した操作は
`Space` とヘルプから使えます。ほかの画面では操作が宣言したキーを保持します。
